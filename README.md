# Praveen Kumar K ("KPK DON") - Official Website & Portfolio

A luxury, ultra-responsive portfolio and landing page showcasing the three extraordinary dimensions of **Praveen Kumar K**, popularly known as **"KPK DON"**:

1. **Playback Singer & Vocal Artist** (Cinematic melodies, live concerts, studio tracking)
2. **Master Pencil Shading Artist** (Hyper-realistic portraits, wildlife, graphite & charcoal)
3. **Academic Topper & Gold Medalist** (Scholastic excellence, university rank 1, academic laurels)

---

## 🌟 Key Features

- **Ambient Background Particles**: Floating gold dust and graphite specks with smooth physics.
- **Dynamic Role Typewriter**: Switches seamlessly between his core identities.
- **Interactive Audio Studio ("Studio KPK")**:
  - Live Web Audio API synthesizer generating melodious acoustic arpeggios directly in the browser (zero dead audio links).
  - Real-time frequency waveform visualizer canvas.
  - Interactive tracklist with duration and live timing tracker.
  - Navbar sound toggle ("Studio Audio") with animated soundwave bars.
- **Interactive Pencil Shading Studio ("Sketch Pad")**:
  - In-browser interactive drawing canvas with realistic graphite texture physics.
  - Grade selector: **2H (Light)**, **HB (Medium)**, **2B (Soft)**, **6B (Dark)**, **Charcoal (9B Velvet)**, **Blending Stump (Smudge)**, and **Eraser**.
  - One-click **Save Your Sketch** (PNG download) and **Clear Paper**.
- **The Graphite Vault & Filterable Gallery**:
  - High-resolution artwork crops showcasing the **A.R. Rahman** tribute, the **Royal Lion**, **Ocular Realism (Eye)**, **Botanical Rose**, **Live Stage Singing**, and **Academic Gold Medals**.
  - Full-screen **Lightbox Modal** with graphite specifications, pencil grade breakdown, and direct commission triggers.
- **Academic Topper Showcase**:
  - Honors, gold medals, citations, and philosophy on how analytical discipline elevates artistic intuition.
- **The "KPK DON" Story**:
  - Narrative celebrating why Praveen is hailed as "KPK DON" across music, art, and academics.
- **Booking & Commission Hub**:
  - Direct inquiry builder with instant WhatsApp launch integration for seamless client bookings.
- **Mobile Responsive & Lightning Fast**:
  - Zero heavy external dependencies, 100% responsive across mobile, tablet, and ultra-wide screens.

## 🚀 How to Run

### Option 1: Double-Click
Simply double-click `index.html` in your file explorer to open it in any modern browser (Chrome, Edge, Firefox, Safari).

### Option 2: Local HTTP Server (Optional)
Run in PowerShell:
```powershell
python -m http.server 8000
```
Then visit: [http://localhost:8000](http://localhost:8000)
